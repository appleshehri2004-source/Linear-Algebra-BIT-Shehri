## Question

Lesson 2.8.1 found two spaces: the column space and the null space. A matrix has **two more**, hiding in its rows. How do all four fit together?

## Numbers

Start with <Formula tex="\text{col 1} = (1, 1)" /> and <Formula tex="k = 2" />:

<Formula display tex="A = \begin{bmatrix} 1 & 2 \\ 1 & 2 \end{bmatrix}" />

**In the input plane:**

- <span class="space">**Row space**</span>: both rows are <Formula tex="(1, 2)" />, so it's the line through <Formula tex="(1, 2)" />.
- <span class="null">**Null space**</span>: <Formula tex="x + 2y = 0" />, the line through <Formula tex="(-2, 1)" />.
- <Formula tex="(1, 2) \cdot (-2, 1) = -2 + 2 = 0" />: at right angles. ✓

**In the output plane:**

- <span class="space">**Column space**</span>: the line through <Formula tex="(1, 1)" />.
- <span class="null">**Left null space**</span>: the null space of <Formula tex="A^T" />. The rows of <Formula tex="A^T" /> are <Formula tex="(1, 1)" /> and <Formula tex="(2, 2)" />, so <Formula tex="y_1 + y_2 = 0" />: the line through <Formula tex="(-1, 1)" />.
- <Formula tex="(1, 1) \cdot (-1, 1) = -1 + 1 = 0" />: at right angles. ✓

## Explain

**The four subspaces** of a matrix <Formula tex="A" />:

| Space | What it holds | Where it lives |
| --- | --- | --- |
| <span class="space">Row space</span> | every mix of the rows | input |
| <span class="null">Null space</span> | every <Formula tex="\vec{x}" /> with <Formula tex="A\vec{x} = \vec{0}" /> | input |
| <span class="space">Column space</span> | every mix of the columns | output |
| <span class="null">Left null space</span> | every <Formula tex="\vec{y}" /> with <Formula tex="A^T\vec{y} = \vec{0}" /> | output |

**Why the row space is at right angles to the null space.** Work out <Formula tex="A\vec{x}" /> one row at a time. Each number in the answer is a row dotted with <Formula tex="\vec{x}" />:

<Formula display tex="A\vec{x} = \begin{bmatrix} \text{row 1} \cdot \vec{x} \\ \text{row 2} \cdot \vec{x} \end{bmatrix}" />

So <Formula tex="A\vec{x} = \vec{0}" /> says <Formula tex="\vec{x}" /> has dot product 0 with **every row**. That's exactly "<Formula tex="\vec{x}" /> is at right angles to the row space". It isn't a coincidence of these numbers: it's what the null space means. That's why the angle stays 90° whatever you drag.

**The same, for the columns.** The rows of <Formula tex="A^T" /> are the columns of <Formula tex="A" />. So the left null space is at right angles to the column space, for the same reason.

**Sizes.** The row space and the column space always have the same dimension: the rank <Formula tex="r" />. For a matrix with <Formula tex="m" /> rows and <Formula tex="n" /> columns:

<Formula display tex="\dim(\text{row space}) + \dim(\text{null space}) = r + (n - r) = n" />

<Formula display tex="\dim(\text{column space}) + \dim(\text{left null space}) = r + (m - r) = m" />

## Go deeper

**Every input splits in two.** Any <Formula tex="\vec{x}" /> is a row space part plus a null space part, at right angles. <Formula tex="A" /> squashes the null space part to <Formula tex="\vec{0}" /> and sends the row space part, one-to-one, onto the column space.

**Why "left" null space?** <Formula tex="A^T\vec{y} = \vec{0}" /> is the same as <Formula tex="\vec{y}^{\,T}\!A = \vec{0}^{\,T}" />: <Formula tex="\vec{y}" /> multiplies <Formula tex="A" /> from the left.

**What it's used for.** When <Formula tex="A\vec{x} = \vec{b}" /> has no solution, the closest you can get is the point of the column space nearest <Formula tex="\vec{b}" />. The gap left over lies in the left null space. That's the idea behind **least squares**, which fits a best line through data.
