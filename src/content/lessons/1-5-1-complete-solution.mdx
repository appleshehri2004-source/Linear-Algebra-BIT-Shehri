## Question

When a system has infinitely many solutions, can you still **write them all down**? What shape do they make, and how are the solutions of <Formula tex="A\mathbf{x} = \mathbf{b}" /> related to those of <Formula tex="A\mathbf{x} = \mathbf{0}" />?

## Numbers

**First, Ax = 0.** The equations are <Formula tex="x + 2y = 0" /> and <Formula tex="2x + 4y = 0" />. <Formula tex="R_2 \to R_2 - 2R_1" /> turns row 2 into <Formula tex="0 = 0" />, so <Formula tex="y" /> is free and <Formula tex="x = -2y" />. Write <Formula tex="t" /> for the free <Formula tex="y" />:

<Formula display tex="\mathbf{x} = \begin{bmatrix} -2t \\ t \end{bmatrix} = t \begin{bmatrix} -2 \\ 1 \end{bmatrix}" />

That is the pink line through the origin, written in **parametric vector form**.

**Now Ax = b, with b = (3, 6).** The same step leaves <Formula tex="x + 2y = 3" />, so <Formula tex="x = 3 - 2y" />:

<Formula display tex="\mathbf{x} = \begin{bmatrix} 3 - 2t \\ t \end{bmatrix} = \begin{bmatrix} 3 \\ 0 \end{bmatrix} + t \begin{bmatrix} -2 \\ 1 \end{bmatrix}" />

Check <Formula tex="t = 1" />: <Formula tex="\mathbf{x} = (1, 1)" />, and <Formula tex="1 + 2 = 3" />, <Formula tex="2 + 4 = 6" />. ✓ The direction <Formula tex="(-2, 1)" /> is the same as for <Formula tex="A\mathbf{x} = \mathbf{0}" />: only the starting point moved.

With <Formula tex="\mathbf{b} = (3, 7)" /> instead, row 2 becomes <Formula tex="0 = 1" />: inconsistent, no solution at all.

**In 3D.** One equation, <Formula tex="x + 2y - z = 0" />, has two free unknowns, <Formula tex="y" /> and <Formula tex="z" />. Then <Formula tex="x = -2y + z" />, and

<Formula display tex="\mathbf{x} = y \begin{bmatrix} -2 \\ 1 \\ 0 \end{bmatrix} + z \begin{bmatrix} 1 \\ 0 \\ 1 \end{bmatrix}," />

a plane through the origin, spanned by those two vectors.

## Explain

**Homogeneous systems.** A system <Formula tex="A\mathbf{x} = \mathbf{0}" /> is called *homogeneous*. It always has the solution <Formula tex="\mathbf{x} = \mathbf{0}" />, the *trivial solution*. The real question is whether it has a *nontrivial* one, and the answer comes from §1.2: **there is a nontrivial solution exactly when there is at least one free unknown.**

**What the solutions look like.** Each free unknown gives one vector, and every solution of <Formula tex="A\mathbf{x} = \mathbf{0}" /> is a mix of them. So the solution set is a span: just the origin (no free unknowns), a line through the origin (one), a plane through the origin (two), and so on.

**Parametric vector form** means writing the solutions as <Formula tex="\mathbf{x} = t\,\mathbf{v}" /> or <Formula tex="\mathbf{x} = s\,\mathbf{u} + t\,\mathbf{v}" />, with the free unknowns as the numbers <Formula tex="s, t" /> that can be anything.

**Ax = b is a shifted copy.** Suppose <Formula tex="\mathbf{p}" /> is one solution of <Formula tex="A\mathbf{x} = \mathbf{b}" />. Then every solution is

<Formula display tex="\mathbf{x} = \mathbf{p} + \mathbf{v}_h, \qquad \text{where } \mathbf{v}_h \text{ is any solution of } A\mathbf{x} = \mathbf{0}." />

Why? The two rules from Lesson 1.4.1 do it. <Formula tex="A(\mathbf{p} + \mathbf{v}_h) = A\mathbf{p} + A\mathbf{v}_h = \mathbf{b} + \mathbf{0} = \mathbf{b}" />, so each of these is a solution. And if <Formula tex="\mathbf{w}" /> is any solution, then <Formula tex="A(\mathbf{w} - \mathbf{p}) = \mathbf{b} - \mathbf{b} = \mathbf{0}" />, so <Formula tex="\mathbf{w}" /> is <Formula tex="\mathbf{p}" /> plus a solution of the homogeneous system. In the picture: the gold line is the pink line slid over to pass through <Formula tex="\mathbf{p}" />. (That only works when <Formula tex="A\mathbf{x} = \mathbf{b}" /> has at least one solution; off the violet line, there is none.)

**A recipe for writing it down.**

1. Row reduce the augmented matrix to reduced echelon form.
2. Write each basic unknown in terms of the free ones.
3. Write <Formula tex="\mathbf{x}" /> as a column, and split it: a constant part (<Formula tex="\mathbf{p}" />) plus one vector for each free unknown.

## Predict

The solutions of <Formula tex="A\mathbf{x} = \mathbf{0}" /> are all multiples of <Formula tex="(1, -1, 2)" />, and <Formula tex="(4, 0, 1)" /> is one solution of <Formula tex="A\mathbf{x} = \mathbf{b}" />. Is <Formula tex="(6, -2, 5)" /> also a solution of <Formula tex="A\mathbf{x} = \mathbf{b}" />?

<details>
  <summary>Reveal</summary>
  Yes. <Formula tex="(6, -2, 5) - (4, 0, 1) = (2, -2, 4) = 2\,(1, -1, 2)" />, a solution of the homogeneous system. So <Formula tex="(6, -2, 5)" /> is <Formula tex="\mathbf{p}" /> plus a solution of <Formula tex="A\mathbf{x} = \mathbf{0}" />: it is on the shifted line.
</details>

## Go deeper

**The particular solution isn't special.** Setting the free unknowns to 0 is just a convenient choice. Any point on the gold line works as <Formula tex="\mathbf{p}" />.

**Differential equations work the same way.** "One particular solution, plus everything the left side sends to 0" is also how linear differential equations are solved. It works for the same reason: the two rules <Formula tex="A(\mathbf{u} + \mathbf{v}) = A\mathbf{u} + A\mathbf{v}" /> and <Formula tex="A(c\mathbf{u}) = cA\mathbf{u}" />. MIT 18.06 Lecture 8 (linked below) solves <Formula tex="A\mathbf{x} = \mathbf{b}" /> this way for bigger matrices.
