## Question

When <Formula tex="\det A = 0" />, there is no single answer to <Formula tex="A\vec{x} = \vec{b}" />. Is there **no** answer, or **lots**? And if there are lots, what do they look like?

## Numbers

<Formula tex="A" /> is the rank 1 matrix from Lesson 2.8.1. With <Formula tex="\vec{b} = (3, 6)" />, the equations are:

<Formula display tex="\begin{cases} x + 2y = 3 \\ 2x + 4y = 6 \end{cases}" />

Elimination: <Formula tex="R_2 \to R_2 - 2R_1" /> turns row 2 into <Formula tex="0 = 0" />. That's always true, so only <Formula tex="x + 2y = 3" /> is left, and <Formula tex="y" /> can be anything (it is **free**).

- Choose <Formula tex="y = 0" />: then <Formula tex="x = 3" />. One **particular solution** is <Formula tex="(3, 0)" />.
- The null space is the line through <Formula tex="(-2, 1)" /> (Lesson 2.8.1).

<Formula display tex="\vec{x} = \begin{bmatrix} 3 \\ 0 \end{bmatrix} + t\begin{bmatrix} -2 \\ 1 \end{bmatrix}" />

Check <Formula tex="t = 1" />: <Formula tex="\vec{x} = (1, 1)" />, and <Formula tex="1 + 2 \cdot 1 = 3" />. ✓

Now move <Formula tex="\vec{b}" /> to <Formula tex="(3, 7)" />. The same step gives <Formula tex="0 = 7 - 2 \cdot 3 = 1" />. That's never true: **no solution**.

## Explain

<Formula tex="A\vec{x}" /> always lands in the <span class="space">**column space**</span>. So:

- If <Formula tex="\vec{b}" /> is **off** the column space, nothing lands there: **no solution**. Elimination shows this as a row saying <Formula tex="0 = 1" />.
- If <Formula tex="\vec{b}" /> is **on** it, take any one solution <Formula tex="\vec{x}_p" /> and add anything from the <span class="null">**null space**</span>:

<Formula display tex="\vec{x} = \vec{x}_p + \vec{x}_n, \qquad A(\vec{x}_p + \vec{x}_n) = \vec{b} + \vec{0} = \vec{b}" />

That's the **complete solution**: one particular solution, plus the whole null space. It is the <span class="null">pink</span> line slid over to pass through <Formula tex="\vec{x}_p" />, which is why the <span class="sum">**gold**</span> line is parallel to the pink one.

It also works the other way round: if <Formula tex="\vec{x}_1" /> and <Formula tex="\vec{x}_2" /> both solve it, then <Formula tex="A(\vec{x}_1 - \vec{x}_2) = \vec{b} - \vec{b} = \vec{0}" />. Any two solutions differ by a null space vector, so the gold line holds **every** solution.

| <Formula tex="\vec{b}" /> in the column space? | Null space | Solutions |
| --- | --- | --- |
| No | anything | none |
| Yes | just <Formula tex="\vec{0}" /> | exactly one |
| Yes | a line (or more) | infinitely many |

## Go deeper

**In 3D**, the complete solution can be a point, a line or a plane: one particular solution, plus a null space of dimension 0, 1 or 2. Each free unknown adds one dimension.

**The particular solution isn't special.** Setting the free unknowns to 0 is just a convenient choice. Any point on the gold line works as <Formula tex="\vec{x}_p" />.

**Differential equations work the same way.** "Particular solution + everything the left side sends to 0" is how linear differential equations are solved too. It works because both are linear.
